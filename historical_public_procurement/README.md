## Historical Public Procurement Data

Historical information on public procurement and government contracting in Uruguay, available in **Open Contracting Data Standard (OCDS)** format from **2002 onward**.

The dataset is organized by year and contains monthly JSON files with information on **procurement notices and contract awards**. Files are provided as compressed ZIP archives for bulk download.

**Source:** Agencia Reguladora de Compras Estatales (ARCE)
**Format:** OCDS / JSON
**Coverage:** 2002–present
**License:** Uruguay Open Data License
**Update frequency:** Annual
